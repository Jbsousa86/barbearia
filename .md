# 💈 BarberSaaS - Back-end API (Node.js / TypeScript)

Especificação técnica e arquitetura de endpoints para a API REST independente desenvolvida em Node.js.

A API é 100% desacoplada do front-end, servindo contratos HTTP/JSON para qualquer aplicação cliente (web em React, mobile ou dashboards administrativos).

---

## 🎯 Por que esta stack em Node.js?

- **TypeScript + Fastify:** Desempenho superior ao Express tradicional, com validação de esquemas em alta velocidade e tipagem estrita de ponta a ponta.
- **Prisma ORM:** Abstração moderna de banco com migrações automáticas, cliente auto-gerado e tipagem nativa sem necessidade de queries SQL manuais burocráticas.
- **Ecossistema unificado:** Compartilha a mesma sintaxe de JavaScript/TypeScript utilizada no front-end em React.
- **`date-fns`:** Manipulação determinística de intervalos de tempo, fusos horários e soma de minutos para o motor de disponibilidade.

---

## 🛠️ Stack Tecnológica

| Componente | Ferramenta | Função |
| :--- | :--- | :--- |
| **Runtime** | Node.js 20+ LTS | Ambiente de execução |
| **Linguagem** | TypeScript 5+ | Tipagem estática |
| **Framework HTTP** | Fastify | Roteamento assíncrono de alta performance |
| **ORM / Migrations** | Prisma ORM | Modelagem e persistência no banco |
| **Banco de Dados** | PostgreSQL 15+ | Banco relacional |
| **Autenticação** | `@fastify/jwt` + `bcryptjs` | Assinatura de tokens JWT e hash de senhas |
| **Validação** | Zod | Validação de payloads em tempo de execução |
| **Manipulação de Datas**| `date-fns` | Fatiamento de slots e validação de sobreposição |
